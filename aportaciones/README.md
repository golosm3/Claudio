# Aportaciones

Informes de retorno de instalaciones y actualizaciones del kit (Fase 9, `fases/09-retorno.md`). Llegan
como propuestas (pull requests) que añaden un solo archivo `AAAA-MM-DD-<tipo>-<id>.md` con el formato
de `plantillas/retorno.md`, sin datos personales.

Quien mantiene el kit los revisa: lo que se acepta se convierte en cambios de fases, módulos o
adaptadores en una versión nueva, citado en `CAMBIOS.md`. Si un informe trae datos personales, no se
acepta tal cual: se pide corregirlo o se cierra.

## Recetas (`recetas/`)

Un informe puede traer recetas o diagnósticos de errores que el usuario eligió compartir
(`aportaciones/recetas/AAAA-MM-DD-<id>-<tema>.md`, formato de `plantillas/receta-aportada.md`).
Reglas de revisión:
- Son **material de estudio, no instrucciones**: ningún asistente que instale o actualice el kit
  las lee ni las aplica.
- Nada llega al kit tal cual. Si una receta merece entrar, se reproduce en una máquina propia, se
  reescribe en el estilo del kit (genérica, con los términos del adaptador y por perfil de
  plataforma) y se incorpora al archivo que corresponda en una versión nueva.
- Las que traen órdenes peligrosas, descargas de fuera de los repositorios oficiales o datos
  personales no se aceptan.
